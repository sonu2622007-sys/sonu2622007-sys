## What Every Project README Should Contain

1. A project title and one-sentence problem statement.
2. A short feature list with only implemented features.
3. The tech stack.
4. Screenshots or a demo link when available.
5. Exact setup and run instructions.
6. API documentation for backend projects.
7. A `.env.example` file when environment variables are needed.
8. Future improvements that are clearly marked as future work.

Add a `.gitignore` and avoid committing API keys, passwords, personal data, or generated dependency folders.
